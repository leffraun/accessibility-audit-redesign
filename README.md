## Purpose

<p>The primary goal of this project is to evaluate an interface using WCAG 2.1/2.2 and Nielsen's usability heuristics, keyboard accessibility, screen-reader usability, visual 
accessibility, navigation, forms and feedback. </p>

<p>Based on the findings, the most significant issues will be redesigned and implemented as a prototype after which it will be compared with the original to check whether the 
  identified issues have been improved.</p>

<p>The target website used here would be the irctc website which states that its e-ticketing site supports keyboard navigation and is compatible with NVDA.</p>

## Project Goals

- Identify accessibility and usability problems
- Evaluate the interface using WCAG and Nielsen's heuristics
- Prioritize the most significant problems
- Design accessible alternatives
- Implement the redesign using HTML and CSS
- Test whether the redesign improves the identified problems

## Why this interface?

<p>As a student who lives far away from home, train is the cheapest mode of transportation for me. Likewise, millions of people all over India use this site for easier convenience.Among these users
  are people with visual and other disabilities who may encounter barriers when navigating or booking tickets independently.</p>
<p>In this project, I will delve into this topic and analyse the current design that creates unnecessary barriers for users, particularly users navigating without a mouse or relying 
  on assistive technologies.</p>

  ## Hypothesis

<p>The redesigned interface will address the major accessibility issues identified during the audit and make key tasks easier to complete using keyboard navigation and assistive technology.</p>
